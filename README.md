## 👋 Welcome to Brian Labs

An independent software engineering lab by [Brian Muigai](https://github.com/BrianGMuigai), building reliable backend systems and the data layers behind them.

### 🚀 Focus Areas

- **Backend architecture and APIs:** layered Spring Boot services, deliberate transaction boundaries and consistent error contracts
- **Data-layer design:** normalised PostgreSQL and SQL Server schemas, versioned migrations and concurrency control chosen per write path
- **Developer tooling:** automation scripts, CI workflows and small open-source utilities

### 🛠️ Tech Stack

`Java` • `Spring Boot` • `Python` • `PostgreSQL` • `SQL Server` • `Flyway` • `Docker` • `GitHub Actions` • `Linux`

### 📌 Featured Project

- [Hospital Management System](https://github.com/brian-labs/Hospital-System): a Spring Boot backend on a 52-table PostgreSQL schema, with design notes on where each rule is enforced and how concurrent writes are handled. Individual project, in development.
